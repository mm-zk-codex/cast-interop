# Contributing to Cast interop

Thank you for your interest in Cast interop! We're grateful that you'd like to help improve the project.

## A Note on External Contributions

This project is primarily developed and maintained by our internal team. Due to the complexity of the codebase, the tight coordination required between components, and our internal roadmap, **we are generally unable to accept external pull requests at this time.**

We understand this may be disappointing, and we genuinely appreciate the enthusiasm. This isn't a reflection of the quality of any potential contribution — it's simply a matter of how we need to manage development internally to move quickly and safely.

## How You _Can_ Help

Even though we can't accept code contributions right now, there are still meaningful ways to get involved:

### 🐛 Report Bugs

If you encounter a bug, please [open an issue](../../issues/new). A great bug report includes:

- A clear, descriptive title
- Steps to reproduce the issue
- Expected vs. actual behavior
- Environment details (OS, version, etc.)
- Any relevant logs or screenshots

### 💡 Suggest Features

Have an idea that would make the project better? We'd love to hear it. Open an issue with the `feature-request` label and describe:

- The problem you're trying to solve
- Your proposed solution
- Any alternatives you've considered

### 📖 Improve Documentation

Spotted a typo, unclear explanation, or missing documentation? Feel free to open an issue pointing it out. For small documentation fixes, we may accept PRs on a case-by-case basis.

### 💬 Join the Discussion

Participate in [GitHub Discussions](../../discussions) or our community channels. Answering questions, sharing use cases, and providing feedback all help shape the direction of the project.

## If You've Already Opened a PR

If you've submitted a pull request and are reading this — thank you, and we're sorry if this comes as a surprise. We'll do our best to review it and let you know if it's something we can incorporate, but please understand that most external PRs will be respectfully declined.

## Security Vulnerabilities

If you've discovered a security vulnerability, **please do not open a public issue.** Instead, refer to our [SECURITY.md](./SECURITY.md) for responsible disclosure instructions.

## Code of Conduct

Please note that this project adheres to a [Code of Conduct](./CODE_OF_CONDUCT.md). By participating, you are expected to uphold this standard.

---

We truly value your interest and support. Even if we can't accept code contributions today, that may change in the future — so please stay tuned and keep building with us. 🙏
